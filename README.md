# Análisis de datos – Portafolio de Laury Martínez

Ingeniera electrónica. Estos tres casos son el proyecto final del **Certificado de Análisis de Datos de Google** (Coursera). Uso el análisis de datos para mejorar la recolección y el procesamiento de datos en automatización.

Todos los casos siguen el proceso **Preguntar → Preparar → Procesar → Analizar → Compartir → Actuar**, usan solo datos públicos y están hechos en **Python (pandas)**.

| Caso | Pregunta | Datos | Informe |
|---|---|---|---|
| [01 · Cyclistic](01-cyclistic/) | ¿En qué se diferencian los socios anuales de los usuarios ocasionales? | Divvy, abr 2019 – mar 2020 (3,9 millones de viajes) | [PDF](01-cyclistic/Informe_tecnico_Cyclistic.pdf) |
| [02 · Bellabeat](02-bellabeat/) | ¿Qué tendencias de uso de dispositivos inteligentes sirven para la estrategia de Bellabeat? | FitBit Fitness Tracker + datos complementarios de sueño y gimnasio | [PDF](02-bellabeat/Informe_tecnico_Bellabeat.pdf) |
| [03 · Llamadas comerciales](03-llamadas-comerciales/) | ¿Qué patrones de llamada generan reclamos? (para una compañía de telecomunicaciones en Chile) | FTC Do Not Call, EE.UU. (178.227 reclamos) | [PDF](03-llamadas-comerciales/Informe_tecnico_Llamadas.pdf) |

## Estructura de cada carpeta
- `codigo/`: script de limpieza y análisis.
- `resultados/`: tablas resumen que genera el script (CSV y `resumen.json`).
- `graficos/`: gráficos principales del análisis.
- `Informe_tecnico_*.pdf`: informe con gráficos, recomendaciones y limitaciones.

Los datos originales no se incluyen por su tamaño; cada carpeta indica dónde descargarlos.
